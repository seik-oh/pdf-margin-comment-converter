# PDF Margin Comments 📝

**PDF에 달아둔 코멘트를 Word 문서처럼 오른쪽 여백에 펼쳐서 보여주는 맥(macOS) 앱**

PDF 파일을 앱 아이콘에 끌어다 놓기만 하면, 하이라이트마다 달아둔 메모가 페이지 옆에 박스로 정리되고, 본문의 위치와 점선으로 연결된 새 PDF가 만들어집니다.

![결과 미리보기](preview.png)

> Move PDF annotation comments into a Word-style right margin. A simple drag-and-drop app for macOS (works great with Zotero).

## 설치하기 (처음 한 번만)

설치는 **딱 한 번만** 하면 됩니다. 5분 정도 걸려요.

### 1단계. 파일 내려받기

1. 이 페이지 위쪽의 초록색 **`<> Code`** 버튼을 누릅니다.
2. **`Download ZIP`** 을 누릅니다.
3. 다운로드 폴더에 생긴 ZIP 파일을 **더블클릭**해서 압축을 풉니다.
   → `pdf-margin-comments-main` 같은 이름의 폴더가 생깁니다.

### 2단계. 터미널 열기

터미널은 맥에 기본으로 들어 있는 프로그램이에요. 명령어를 몇 개 붙여넣기만 하면 되니 겁먹지 않으셔도 됩니다.

1. 키보드에서 **`⌘ Command` + `Space`** 를 누릅니다.
2. `터미널` (또는 `Terminal`) 이라고 입력하고 **엔터**를 누릅니다.

### 3단계. 파이썬 준비 확인

터미널에 아래를 붙여넣고 **엔터**를 누르세요.

```bash
python3 --version
```

- `Python 3.x.x` 처럼 버전이 나오면 → **4단계로 넘어가세요.**
- **"개발자 도구를 설치하시겠습니까?"** 라는 창이 뜨면 → **`설치`** 를 누르고 끝날 때까지 기다린 뒤(몇 분 걸려요), 위 명령을 한 번 더 실행해서 버전이 나오는지 확인하세요.

### 4단계. 앱 만들기

1. 터미널에 `bash` 와 **띄어쓰기 한 칸**을 입력합니다. (**엔터는 아직 누르지 마세요!**)

   ```
   bash 
   ```

2. Finder에서 1단계에서 푼 폴더를 열고, 그 안의 **`install_app.sh`** 파일을 마우스로 잡아 **터미널 창 위에 끌어다 놓습니다.**
   → 아래처럼 파일 경로가 자동으로 입력됩니다.

   ```
   bash /Users/내이름/Downloads/pdf-margin-comments-main/install_app.sh
   ```

3. 이제 **엔터**를 누릅니다.

아래처럼 나오면 성공입니다 🎉

```
사용할 파이썬: /Library/Developer/CommandLineTools/usr/bin/python3
✅ 완료! 바탕화면에 'PDF 코멘트 여백' 앱이 생겼어요.
```

> 중간에 `replacing existing signature` 같은 문구가 나와도 정상이니 신경 쓰지 않으셔도 됩니다.

이제 터미널은 닫아도 됩니다. **다시 열 일은 없어요.**

**바탕화면**에 **`PDF 코멘트 여백`** 앱이 생겼습니다. 원하면 `응용 프로그램` 폴더나 Dock으로 옮겨서 쓰셔도 됩니다.

## 사용하기

### 방법 A. 끌어다 놓기 (가장 쉬움)

PDF 파일을 **`PDF 코멘트 여백`** 앱 아이콘 위에 **끌어다 놓으세요.**
여러 개를 한꺼번에 놓아도 됩니다.

### 방법 B. 더블클릭

1. **`PDF 코멘트 여백`** 앱을 **더블클릭**합니다.
2. 파일 선택 창에서 PDF를 고르고 **`열기`** 를 누릅니다. (`⌘ Command`를 누른 채 클릭하면 여러 개 선택 가능)

### 결과 확인

잠시 후 결과 창이 뜹니다.

```
완료: 코멘트 12개 → /Users/.../논문제목_코멘트.pdf
```

- **`결과 열기`** 를 누르면 완성된 PDF가 바로 열립니다.
- 결과 파일은 **원본과 같은 폴더**에 **`원본이름_코멘트.pdf`** 로 저장됩니다.
- **원본 파일은 전혀 바뀌지 않습니다.**

> 💡 처음 실행할 때 **"다운로드 폴더에 접근하려고 합니다"** 같은 창이 뜨면 **`허용`** 을 눌러주세요.

## Zotero 사용자라면 꼭 읽어주세요

Zotero는 주석(하이라이트, 메모)을 PDF 파일 안이 아니라 **Zotero 자체 데이터베이스에 저장**합니다.
그래서 Zotero 저장 폴더에 있는 PDF를 그대로 넣으면 **코멘트가 0개**로 나옵니다.

**반드시 아래처럼 "주석이 포함된 PDF"를 먼저 내보내세요.**

1. Zotero 라이브러리에서 논문의 **PDF 첨부파일을 우클릭**합니다.
2. **`PDF 내보내기…`** (Export PDF…) 를 선택합니다.
   - 또는 PDF를 Zotero에서 연 상태로 **`파일 → 다른 이름으로 저장…`**
3. 원하는 곳(예: 다운로드 폴더)에 저장합니다.
4. 저장한 파일을 앱에 끌어다 놓습니다. 끝!

### 다른 PDF 앱에서 단 주석도 되나요?

네. 이 앱은 Zotero 전용이 아니라, **PDF 파일 안에 표준 방식으로 저장된 주석**이면 무엇이든 읽습니다.
Adobe Acrobat / Reader, 미리보기(Preview), PDF Expert, Skim, 알PDF 등에서 단 코멘트도 사용할 수 있어요.

단, GoodNotes · Notability처럼 주석을 **그림으로 굳혀서(평면화)** 내보내는 앱은 코멘트 글자를 읽을 수 없습니다.

## 어떤 주석이 여백에 나오나요?

| 주석 종류 | 여백에 표시? | 설명 |
|---|---|---|
| 하이라이트 + 코멘트 | ✅ | 하이라이트 색깔 그대로 박스와 점선이 그려져요 |
| 밑줄 / 취소선 + 코멘트 | ✅ | |
| 스티키 노트(메모 아이콘) | ✅ | |
| 도형 · 영역 · 펜 + 코멘트 | ✅ | |
| 코멘트 **없는** 하이라이트 | ➖ | 본문에 색칠만 그대로 보여요 |
| 텍스트 박스 (페이지에 직접 쓴 글) | ➖ | 이미 본문에 보이므로 여백에 따로 넣지 않아요 |

그 밖의 특징:

- 코멘트가 몰려 있어도 **서로 겹치지 않게** 자동으로 위아래로 배치됩니다.
- 코멘트가 너무 많으면 한 페이지에 들어가도록 **글자 크기가 조금 작아집니다.**
- 원래의 하이라이트·주석은 **그대로 남아 있어서** 클릭하면 예전처럼 열립니다.
- 한글·영어 모두 지원합니다.

## 문제가 생겼을 때

<details>
<summary><b>"코멘트 0개"라고 나와요</b></summary>

- **Zotero 사용자:** Zotero 폴더의 원본 PDF를 넣으신 거예요. [위 안내](#zotero-사용자라면-꼭-읽어주세요)대로 `PDF 내보내기…` 한 파일을 넣어주세요.
- 하이라이트에 **코멘트(메모 글)를 안 적었다면** 여백에 나올 내용이 없어서 0개로 나옵니다.
- 주석이 평면화된 PDF라면 읽을 수 없습니다.

</details>

<details>
<summary><b>설치할 때 <code>python3를 찾지 못했어요</code> 라고 나와요</b></summary>

[3단계](#3단계-파이썬-준비-확인)의 `python3 --version` 을 먼저 실행해서 개발자 도구를 설치한 뒤, 설치를 다시 해주세요.

</details>

<details>
<summary><b>설치할 때 <code>margin_comments.py 를 ... 넣어주세요</code> 라고 나와요</b></summary>

`install_app.sh` 와 `margin_comments.py` 가 **같은 폴더**에 있어야 합니다.
ZIP을 푼 폴더에서 파일을 옮기지 말고 그대로 실행해 주세요.

</details>

<details>
<summary><b>앱을 실행했는데 "오류"가 나오며 <code>Operation not permitted</code> 가 보여요</b></summary>

맥이 폴더 접근을 막은 거예요.

1. ` 메뉴 → 시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더` 로 갑니다.
2. **`PDF 코멘트 여백`** 을 찾아 다운로드·데스크탑·문서 폴더 접근을 **켜주세요.**

</details>

<details>
<summary><b>오류에 <code>No module named 'pypdf'</code> (또는 reportlab) 가 보여요</b></summary>

필요한 부품 설치가 빠진 경우예요. 터미널에서 아래를 실행한 뒤 앱을 다시 써보세요.

```bash
python3 -m pip install --user pypdf reportlab
```

`externally-managed-environment` 오류가 나오면 이렇게 실행하세요.

```bash
python3 -m pip install --user --break-system-packages pypdf reportlab
```

</details>

<details>
<summary><b>한글이 네모(□)나 이상한 글자로 나와요</b></summary>

맥에 기본으로 있는 `AppleGothic` 폰트를 사용합니다. 폰트를 지우셨다면 [나눔고딕](https://hangeul.naver.com/font)을 설치해 주세요. 자동으로 찾아서 사용합니다.

</details>

<details>
<summary><b>점선이 엉뚱한 위치를 가리켜요</b></summary>

**회전된 페이지**(가로로 돌려진 페이지)가 있는 PDF에서는 위치가 어긋날 수 있습니다. 알려진 제한 사항이에요.

</details>

<details>
<summary><b>코멘트가 너무 많아서 글자가 작아요</b></summary>

한 페이지에 코멘트가 아주 많으면 자동으로 글자가 작아집니다. [여백 폭을 넓히면](#설정-바꾸기) 조금 나아집니다.

</details>

그래도 해결이 안 되면 [Issues](../../issues) 에 **오류 메시지를 그대로 복사해서** 남겨주세요.

## 고급: 터미널로 직접 실행 / 설정 바꾸기

### 터미널로 직접 실행

앱 없이 스크립트만 쓸 수도 있습니다. **Windows / Linux**에서도 이 방법으로 쓸 수 있어요.

```bash
# 필요한 부품 설치 (처음 한 번)
python3 -m pip install pypdf reportlab

# 실행: 결과는 "원본이름_코멘트.pdf"로 저장
python3 margin_comments.py 입력.pdf

# 결과 파일 이름을 직접 정하기
python3 margin_comments.py 입력.pdf 결과.pdf
```

> 파일 이름에 띄어쓰기가 있으면 `"논문 제목.pdf"` 처럼 따옴표로 감싸세요.

### 설정 바꾸기

`margin_comments.py` 를 텍스트 편집기로 열면 위쪽에 아래 설정이 있습니다.

| 설정 | 기본값 | 의미 |
|---|---|---|
| `MARGIN_W` | `230` | 오른쪽에 추가할 여백의 폭 (클수록 코멘트 박스가 넓어짐) |
| `FONT_SIZE` | `8.5` | 코멘트 글자 크기 |
| `MIN_FONT` | `6` | 코멘트가 많을 때 줄어들 수 있는 최소 글자 크기 |
| `GAP` | `6` | 코멘트 박스 사이 간격 |
| `SKIP_SUBTYPES` | `"/Popup", "/Link", "/Widget", "/FreeText"` | 여백에 넣지 않을 주석 종류 |

예) 스티키 노트(메모 아이콘)도 여백에서 빼고 싶다면 `SKIP_SUBTYPES` 에 `"/Text"` 를 추가하세요.

```python
SKIP_SUBTYPES = {"/Popup", "/Link", "/Widget", "/FreeText", "/Text"}
```

설정을 바꾼 뒤에는 [4단계](#4단계-앱-만들기)를 다시 실행해야 앱에 반영됩니다.

## 파일 구성 · 라이선스

```
pdf-margin-comments/
├── margin_comments.py      # 변환 프로그램 본체
├── install_app.sh          # 맥 앱을 만들어 주는 설치 스크립트
├── preview.png             # README 미리보기 이미지
└── README.md               # 지금 보고 있는 설명서
```

### 작동 원리 (궁금한 분만)

1. PDF 각 페이지의 오른쪽을 넓혀 여백을 만듭니다.
2. 페이지의 주석 중 코멘트가 있는 것만 골라 위치와 색을 읽습니다.
3. 여백에 코멘트 박스를 배치하고, 원래 위치와 점선으로 연결합니다.
4. 원본은 그대로 두고 새 PDF로 저장합니다.

맥 앱은 AppleScript로 만든 작은 "드롭릿"으로, 파일을 받아 위 파이썬 스크립트를 실행해 주는 역할만 합니다.
